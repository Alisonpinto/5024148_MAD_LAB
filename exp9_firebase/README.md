# Experiment 9: Connect Flutter UI with Firebase Database

## Aim
To integrate a Flutter application with Firebase Realtime Database to read and write data in real-time.

## Theory
- **Realtime Database**: A cloud-hosted NoSQL database by Firebase where data is synced across all clients in real-time.
- **JSON Tree Structure**: In Realtime Database, all data is stored as one large JSON tree (unlike tables in SQL). Nodes act as keys mapped to values, which can be simple strings/numbers or nested JSON objects.
- **Realtime DB vs Firestore**: Realtime DB stores data as a single monolithic JSON tree and is great for low-latency syncing. Firestore stores data in Documents organized into Collections, offering richer queries, more scalable structuring, and better offline support.

## Setup Steps
1. Create a new project on [console.firebase.google.com](https://console.firebase.google.com/).
2. Navigate to **Build > Realtime Database**, click **Create Database**, and start in **test mode** (so read/write rules are public for development).
3. Install the FlutterFire CLI globally:
   ```bash
   dart pub global activate flutterfire_cli
   ```
4. Configure Firebase for your project by running the following command in your terminal and selecting the project you created:
   ```bash
   flutterfire configure
   ```
   *(This automatically generates `firebase_options.dart` and sets up `google-services.json` for Android and similar config files for iOS/Web)*
5. The `firebase_core` and `firebase_database` packages must be added to your `pubspec.yaml` (which this repository already includes).

## Code Structure
- **`Firebase.initializeApp()`**: Must be called in `main()` to initialize the connection to Firebase using the options generated by the CLI.
- **`push()`**: A `DatabaseReference` method that generates a unique key (based on timestamp), allowing multiple items to be added to a list (like `students/`) without colliding.
- **`remove()`**: A method to delete data at a specific database path.
- **`StreamBuilder` & `onValue`**: `DatabaseReference.onValue` returns a Stream of events. A `StreamBuilder` listens to this stream and automatically rebuilds the UI whenever data is added, updated, or removed in the database.
